# editin — 누구나 쉽게, 그러나 제대로 하는 영상 편집기

설치 없이 브라우저에서 바로 쓰는 영상 편집기입니다.

- **편집이 처음인 사람**도 안내와 자동 기능만 따라가면 보통 수준의 결과물이 나오도록 만들었습니다.
- **편집해 본 사람**은 단축키, 다중 트랙, 세부 수치, 타임코드를 써서 빠르게 작업할 수 있습니다.

모든 처리는 내 컴퓨터의 브라우저 안에서만 이루어지고, 파일은 어디에도 업로드되지 않습니다.

## 윈도우 앱 (추천)

[Releases](https://github.com/Jedidiah1926/editin/releases)에서 `editin-Setup-x.x.x.exe`를 받아 설치하면 됩니다.

- 유튜브 가져오기가 앱 안에서 바로 됩니다. 도우미를 따로 켜거나 yt-dlp·ffmpeg를 설치할 필요가 없습니다.
- 앱에 들어 있는 yt-dlp는 **하루 한 번 자동으로 최신 버전으로 업데이트**됩니다. 공식 체크섬(SHA2-256SUMS)으로 확인한 파일만 교체합니다. 유튜브 가져오기 창에서 **지금 업데이트**를 눌러도 됩니다.
- yt-dlp가 유튜브를 처리할 때 필요한 JavaScript 런타임으로 앱에 들어 있는 Node(Electron)를 씁니다.
- 내보낸 MP4는 앱 안의 ffmpeg로 소리를 AAC로 바꾸고 faststart를 적용해, 어떤 플레이어에서도 재생됩니다.
- 아직 코드 서명을 하지 않아서 처음 실행할 때 "Windows의 PC 보호" 화면이 나올 수 있습니다. **추가 정보 → 실행**을 누르세요.

### 앱 개발 · 배포

```bash
npm install
npm run app                 # 개발 중 실행 (vendor/에 yt-dlp를 넣어 두면 그걸 씀)
npm run dist:win            # 윈도우 설치 파일 만들기 (윈도우에서 실행)
```

`v`로 시작하는 태그(예: `v0.1.0`)를 올리면 GitHub Actions(`.github/workflows/release.yml`)가 윈도우에서 앱을 빌드합니다. 이때 yt-dlp.exe를 받아 체크섬을 확인하고, 앱이 실행되는지 점검한 뒤 Release에 설치 파일을 올립니다.

## 웹 버전 실행

ES 모듈을 쓰기 때문에 로컬 웹 서버로 열어야 합니다. 빌드 과정은 없습니다.

```bash
npm start            # http://localhost:8080
# 또는
python3 -m http.server 8080
```

최신 Chrome 또는 Edge를 권장합니다. 내보내기에는 MediaRecorder를 쓰고, MP4(H.264)로 저장할 수 있는지는 브라우저에 따라 다릅니다.

## 롱폼 / 숏폼

오른쪽 위에서 영상 형식을 고릅니다.

- **롱폼**: 가로 16:9 (1920×1080). 유튜브 일반 영상용입니다.
- **숏폼**: 세로 9:16 (1080×1920). 쇼츠·릴스·틱톡용입니다.
  - 심플 모드에서는 가로로 찍은 영상도 세로 화면을 꽉 채우도록 가운데를 기준으로 잘라 넣습니다.
  - 화면 아래쪽은 좋아요·댓글 버튼과 설명에 가려지므로 자막을 조금 위로 올립니다. 롱폼으로 돌아가면 원래 위치로 돌아갑니다.
  - 자동 자막의 한 줄 글자 수를 짧게(14자) 추천합니다.

형식을 직접 고르지 않으면 처음 불러온 영상의 비율에 맞춰 자동으로 정해집니다. 정사각(1:1)과 세로 4:5는 프로젝트 설정에서 고를 수 있습니다.

## 두 가지 모드

| | 🌱 심플 | 🎛 전문가 |
|---|---|---|
| 불러오기 | 파일을 놓으면 순서대로 타임라인에 자동 배치, 화면 비율 자동 결정 | 라이브러리에만 추가하고 원하는 위치에 직접 배치 |
| 안내 | 상단 5단계 가이드(불러오기 → 다듬기 → 자막 → 음악 → 내보내기)와 상황별 팁 | 숨김 |
| 속성 패널 | 카드형 프리셋(필터, 자막 스타일, 움직임, 전환) 중심 | 위치·회전·글꼴·프레임 레이트 같은 세부 수치까지 표시, 숫자로 직접 입력 |
| 시간 표기 | `00:12.4` | `00:00:12:15` 타임코드 |

모드는 오른쪽 위에서 언제든 바꿀 수 있습니다. 쉬운 편집을 원하면 **심플**, 세밀한 작업을 원하면 **전문가**를 고르면 됩니다.

## 초보자도 평균 이상의 결과를 얻도록 돕는 기능

- **🪄 무음 자동 컷**: 말이 없는 구간을 찾아 잘라내고 빈틈 없이 이어 붙입니다. 민감도를 조절하면서 얼마나 잘릴지 미리 볼 수 있습니다.
- **🔊 음량 고르게**: 클립마다 다른 소리 크기를 비슷하게 맞춥니다.
- **자동 볼륨(덕킹)**: 배경음악 트랙에 넣은 음악은 말소리가 나오는 동안 자동으로 작아집니다.
- **✨ 원클릭 보정**과 **필터 9종**: 필터 카드에 현재 화면이 미리보기로 표시됩니다.
- **🎙 자동 자막**: 영상 속 말을 받아써서 자막을 만듭니다. 음성 인식 모델(Whisper)이 브라우저 안에서 돌아가므로 음성이 외부로 나가지 않습니다. 처음 한 번은 모델을 내려받습니다(빠르게 약 80MB, 정확하게 약 250MB).
  - 한 줄 최대 글자 수에 맞춰 띄어쓰기·쉼표 위치에서 줄을 나눕니다.
  - 무음 컷으로 잘라낸 영상도 남은 구간에 맞춰 자막을 붙입니다.
  - 조용한 구간에서 나오는 흔한 오인식("시청해주셔서 감사합니다" 등)과 반복 문장을 걸러냅니다.
- **자막 디자인(일반 / 강조)**: 대부분의 말에는 일반 자막을, 하이라이트 순간에는 강조 자막을 씁니다. 디자인을 바꾸면 이미 만든 자막에도 바로 반영됩니다. 강조할 곳은 다음 기준으로 고릅니다.
  - 마커(◆)를 찍은 곳
  - 목소리가 커지는 곳 (자동 감지)
  - 느낌표가 있는 말
  - 지정한 키워드
  - 자막을 하나씩 골라 직접 강조로 바꿀 수도 있습니다.
- **내 템플릿**: 프로젝트를 새로 만들어도 남아 있습니다.
  - **자막 바 이미지**: 자막 바 그림(PNG 등)을 올리면 그 위에 글자를 얹습니다. 단색 배경은 자동으로 지우고, 로고나 둥근 끝 같은 장식은 그대로 둔 채 가운데만 글자 길이에 맞춰 늘립니다. 글자색은 바 색에 맞춰 자동으로 추천합니다.
  - **사진 속 자막 따라하기**: 자막이 찍힌 캡처 사진을 올리면 글자색, 테두리색, 배경 박스를 찾아 같은 느낌의 스타일을 만듭니다.
  - **선택한 자막 모양 저장**: 직접 꾸민 자막을 템플릿으로 저장합니다.
- **자막 스타일 9종**: 기본, 박스, 큰 제목, 예능, 이름표, 강조, 네온, 감성 명조, 미니멀.
- **대본으로 자막 한 번에 만들기**: 한 줄에 자막 하나씩 붙여넣으면 읽기 좋은 길이로 자동 배치됩니다. SRT 파일도 불러오고 저장할 수 있습니다. 자막 디자인과 강조 규칙이 똑같이 적용됩니다.
- **전환 효과 한 번에**, **시작·끝 부드럽게**(페이드 인/아웃, 음악 길이 맞춤), **화면 꽉 채우기**(세로 쇼츠용).
- **🩺 완성도 점검**: 내보내기 전에 검은 화면 구간, 너무 빨리 지나가는 자막, 화면 밖으로 나간 글자, 찢어지는 볼륨, 음악에 묻히는 목소리, 뚝 끊기는 마지막 장면을 찾아 주고, 버튼 한 번으로 고칠 수 있게 합니다.
- **자석 메인 트랙**: 클립을 지우거나 잘라도 빈틈이 생기지 않습니다.
- **두려움 없는 편집**: 모든 작업은 실행 취소할 수 있고(최대 200단계), 삭제 알림에서 바로 되돌릴 수 있으며, 작업 내용은 브라우저에 자동 저장됩니다.

## ▶ 유튜브 · 치지직 링크로 가져오기 (키리누키)

유튜브나 치지직 다시보기(`chzzk.naver.com/video/…`) 링크를 넣고 원하는 구간만 골라 받아서 소스로 씁니다. 치지직은 플레이어를 넣을 수 없어서 썸네일과 '치지직에서 열기'로 시간을 확인합니다. 방송 중인 라이브와 치지직 클립 링크는 아직 가져올 수 없습니다. 구간 받기가 안 되는 영상은 전체를 받은 뒤 자동으로 잘라 냅니다. 긴 라이브 다시보기에서 몇 분만 잘라 숏폼으로 만들 때 편합니다.

1. 미디어 탭의 **▶ 유튜브 링크로 가져오기**를 누르거나, 편집기 아무 곳에서나 유튜브 링크를 **붙여넣기(Ctrl+V)** 합니다.
2. 유튜브 플레이어에서 원하는 장면을 찾아 **지금 위치**로 시작·끝을 정합니다. 시간을 `1:02:03`처럼 직접 적어도 됩니다. 링크에 `?t=`가 있으면 그 시간부터 시작합니다.
3. **이 구간 가져오기**를 누르면 그 구간만 받아서 메인 레이어 끝에 붙입니다.
   - 숏폼이면 **원본 + 흐린 배경**(키리누키에서 많이 쓰는 방식)이나 **가운데 잘라 꽉 채우기**를 고를 수 있습니다.
   - **출처 표시**(채널 이름)를 영상 위에 자동으로 넣을 수 있습니다.

### 처음 한 번 준비

브라우저는 보안상 유튜브 영상을 직접 받을 수 없어서, 내 컴퓨터에서 작은 도우미 프로그램(`tools/yt-helper.mjs`)을 켜 둬야 합니다. 도우미는 [yt-dlp](https://github.com/yt-dlp/yt-dlp)와 ffmpeg로 영상을 받습니다.

```bash
# 1) 설치 (한 번만)
brew install yt-dlp ffmpeg                  # macOS
winget install yt-dlp.yt-dlp Gyan.FFmpeg    # Windows
pip install -U yt-dlp                       # Linux (ffmpeg는 배포판 패키지로)

# 2) 편집기 폴더에서 도우미 켜기 (편집하는 동안 켜 두기)
npm run yt-helper                           # http://127.0.0.1:8787
```

- 도우미는 내 컴퓨터(127.0.0.1)에서만 열리고, 편집기를 연 주소(localhost)에서 온 요청만 받습니다. 다른 주소에서 편집기를 쓴다면 `EDITIN_ALLOWED_ORIGINS=https://내주소 npm run yt-helper`처럼 허용할 주소를 지정하세요.
- 유튜브가 바뀌어 가져오기가 안 되면 `yt-dlp -U`(또는 `pip install -U yt-dlp`)로 yt-dlp를 최신으로 올려 주세요.
- 로그인이 필요한 영상(연령 제한, 멤버십 전용 등)은 가져올 수 없습니다.
- **저작권**: 키리누키는 원본 채널(소속사)의 2차 창작·클립 가이드라인을 확인하고, 허락된 범위에서 만들어 주세요. 유튜브 이용약관상 허락 없는 다운로드는 제한될 수 있습니다.

## 화면 크기 조절 · 자르기

- **크기·위치**: 미리보기에서 영상을 끌면 위치가 바뀌고, 모서리 ■를 끌면 크기가 바뀝니다. 재생 중에도 됩니다. 속성 패널에서는 좌우·상하 위치를 숫자로 맞출 수 있습니다(숏폼 구도 잡기).
- **흐린 배경 채우기**: 맞춤에서 '흐린 배경'을 고르면 원본은 그대로 두고 빈 곳을 같은 영상의 흐린 화면으로 채웁니다.
- **화면 자르기(크롭)**: '가장자리 끌어서 자르기'를 누르거나, 미리보기에서 영상을 더블클릭하거나, `C` 키를 누르면 자르기 모드가 됩니다. 노란 테두리의 가장자리·모서리를 끌어 잘라냅니다. 잘려 나갈 부분은 흐리게 보여 줍니다.
- **⬛ 검은 여백 지우기**: 게임·영화 녹화본처럼 위아래(또는 양옆)에 붙은 검은 띠를 찾아 잘라냅니다.
- **비율로 자르기**: 16:9 / 9:16 / 1:1 / 4:5 비율로 가운데를 잘라 화면을 꽉 채웁니다. 검은 여백을 지운 뒤라면 그 안에서 자릅니다.

## 레이어

- 타임라인 도구 막대의 **＋ 레이어**나 왼쪽 아래 **+ 레이어 추가**로 영상·자막·오디오 레이어를 원하는 만큼 늘릴 수 있습니다.
- 각 레이어의 **⋯** 메뉴(또는 우클릭)에서 이름 바꾸기, 위·아래로 옮기기, 삭제를 할 수 있습니다. 영상 레이어는 위에 있을수록 화면 앞쪽에 보입니다.
- 레이어마다 숨기기·음소거·잠금을 설정할 수 있습니다.

## 전문가를 위한 기능

- 스냅(클립 경계, 재생 위치, 마커, I/O 지점), 드래그 트리밍, 트랙 사이 이동. Shift를 누른 채 드래그하면 스냅이 잠시 꺼집니다.
- 클립별 속도(0.25x~4x), 볼륨(최대 200%), 페이드, 위치·크기·회전·불투명도, 밝기·대비·채도·색온도·비네팅.
- 미리보기에서 끌어 위치를 옮기고 휠로 크기를 조절하며, 가운데 정렬에 자동으로 맞춰집니다. 안전 영역과 3분할 안내선도 켤 수 있습니다.
- 마커, I/O 구간 지정과 구간만 내보내기, 오디오 레벨 미터.

## 알아 둘 점

- 내보내기는 실시간으로 렌더링하므로 영상 길이만큼 시간이 걸립니다. 렌더링하는 동안에는 탭을 열어 두어야 합니다.
- 자동 자막은 처음에 cdn.jsdelivr.net과 huggingface.co에서 엔진과 모델을 내려받습니다. 회사나 학교 네트워크에서 이 주소가 막혀 있으면 쓸 수 없고, 그때는 대본 붙여넣기나 SRT로 같은 디자인을 적용할 수 있습니다. 인식 결과에는 틀린 글자가 있을 수 있으니 자막을 더블클릭해 고치세요.
- 원본 파일은 브라우저 저장소(IndexedDB)에 보관되므로, 아주 큰 파일을 많이 쓰면 저장 공간이 부족할 수 있습니다.
