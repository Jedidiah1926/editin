# editin — 누구나 쉽게, 그러나 제대로 하는 영상 편집기

설치 없이 브라우저에서 바로 쓰는 영상 편집기입니다.

- **편집이 처음인 사람**도 안내와 자동 기능만 따라가면 보통 수준의 결과물이 나오도록 만들었습니다.
- **편집해 본 사람**은 단축키, 다중 트랙, 세부 수치, 타임코드를 써서 빠르게 작업할 수 있습니다.

모든 처리는 내 컴퓨터의 브라우저 안에서만 이루어지고, 파일은 어디에도 업로드되지 않습니다.

## 실행

ES 모듈을 쓰기 때문에 로컬 웹 서버로 열어야 합니다. 빌드 과정은 없습니다.

```bash
npm start            # http://localhost:8080
# 또는
python3 -m http.server 8080
```

최신 Chrome 또는 Edge를 권장합니다. 내보내기에는 MediaRecorder를 쓰고, MP4(H.264)로 저장할 수 있는지는 브라우저에 따라 다릅니다.

## 두 가지 모드

| | 🌱 쉬운 모드 | 🎛 전문가 모드 |
|---|---|---|
| 불러오기 | 파일을 놓으면 순서대로 타임라인에 자동 배치, 화면 비율 자동 결정 | 라이브러리에만 추가하고 원하는 위치에 직접 배치 |
| 안내 | 상단 5단계 가이드(불러오기 → 다듬기 → 자막 → 음악 → 내보내기)와 상황별 팁 | 숨김 |
| 속성 패널 | 카드형 프리셋(필터, 자막 스타일, 움직임, 전환) 중심 | 위치·회전·글꼴·프레임 레이트 같은 세부 수치까지 표시, 숫자로 직접 입력 |
| 시간 표기 | `00:12.4` | `00:00:12:15` 타임코드 |

모드는 오른쪽 위에서 언제든 바꿀 수 있습니다.

## 초보자도 평균 이상의 결과를 얻도록 돕는 기능

- **🪄 무음 자동 컷**: 말이 없는 구간을 찾아 잘라내고 빈틈 없이 이어 붙입니다. 민감도를 조절하면서 얼마나 잘릴지 미리 볼 수 있습니다.
- **🔊 음량 고르게**: 클립마다 다른 소리 크기를 비슷하게 맞춥니다.
- **자동 볼륨(덕킹)**: 배경음악 트랙에 넣은 음악은 말소리가 나오는 동안 자동으로 작아집니다.
- **✨ 원클릭 보정**과 **필터 9종**: 필터 카드에 현재 화면이 미리보기로 표시됩니다.
- **자막 스타일 9종**: 기본, 박스, 큰 제목, 예능, 이름표, 강조, 네온, 감성 명조, 미니멀.
- **대본으로 자막 한 번에 만들기**: 한 줄에 자막 하나씩 붙여넣으면 읽기 좋은 길이로 자동 배치됩니다. SRT 파일도 불러오고 저장할 수 있습니다.
- **전환 효과 한 번에**, **시작·끝 부드럽게**(페이드 인/아웃, 음악 길이 맞춤), **화면 꽉 채우기**(세로 쇼츠용).
- **🩺 완성도 점검**: 내보내기 전에 검은 화면 구간, 너무 빨리 지나가는 자막, 화면 밖으로 나간 글자, 찢어지는 볼륨, 음악에 묻히는 목소리, 뚝 끊기는 마지막 장면을 찾아 주고, 버튼 한 번으로 고칠 수 있게 합니다.
- **자석 메인 트랙**: 클립을 지우거나 잘라도 빈틈이 생기지 않습니다.
- **두려움 없는 편집**: 모든 작업은 실행 취소할 수 있고(최대 200단계), 삭제 알림에서 바로 되돌릴 수 있으며, 작업 내용은 브라우저에 자동 저장됩니다.

## 전문가를 위한 기능

- 다중 트랙(영상/오버레이, 자막, 오디오)을 추가할 수 있고, 트랙마다 숨기기·음소거·잠금을 설정할 수 있습니다.
- 스냅(클립 경계, 재생 위치, 마커, I/O 지점), 드래그 트리밍, 트랙 사이 이동. Shift를 누른 채 드래그하면 스냅이 잠시 꺼집니다.
- 클립별 속도(0.25x~4x), 볼륨(최대 200%), 페이드, 위치·크기·회전·불투명도, 밝기·대비·채도·색온도·비네팅.
- 미리보기에서 끌어 위치를 옮기고 휠로 크기를 조절하며, 가운데 정렬에 자동으로 맞춰집니다. 안전 영역과 3분할 안내선도 켤 수 있습니다.
- 마커, I/O 구간 지정과 구간만 내보내기, 오디오 레벨 미터.

### 단축키

| 키 | 동작 |
|---|---|
| `Space` | 재생 / 일시정지 |
| `J` `K` `L` | 뒤로 / 정지 / 앞으로 (반복해서 누르면 빨라짐) |
| `←` `→` | 1프레임 이동 (`Shift`: 1초) |
| `↑` `↓` | 이전 / 다음 편집점 |
| `S` / `Ctrl+B` | 재생 위치에서 자르기 |
| `Q` / `W` | 재생 위치 앞 / 뒤 잘라내기 (리플) |
| `Delete` / `Shift+Delete` | 삭제 / 삭제 후 빈틈 당기기 |
| `Ctrl+C` `Ctrl+V` `Ctrl+X` `Ctrl+D` | 복사 / 붙여넣기 / 잘라내기 / 복제 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `I` `O` `X` | 구간 시작 / 끝 / 해제 |
| `M` | 마커 |
| `T` | 자막 추가 |
| `N` | 스냅 켜기/끄기 |
| `+` `-` / `Shift+Z` | 확대 / 축소 / 전체 보기 (`Alt`·`Ctrl`+휠도 가능) |
| `Ctrl+E` | 내보내기 |
| `?` | 단축키 도움말 |

## 구조

```
index.html        레이아웃
css/app.css       스타일 (다크 테마, 반응형)
js/app.js         진입점: 패널, 단축키, 가이드, 온보딩, 자동 저장 복원
js/store.js       프로젝트 상태, 실행 취소/다시 실행, IndexedDB 자동 저장
js/engine.js      재생 엔진: 미디어 동기화, 캔버스 합성, WebAudio 믹싱
js/timeline.js    타임라인 UI: 드래그, 트리밍, 스냅, 스크럽, 끌어다 놓기
js/inspector.js   속성 패널 (쉬운/전문가 모드)
js/ops.js         편집 동작 (자르기, 삭제, 복제, 붙여넣기, 트림)
js/smart.js       무음 컷, 음량 맞춤, 보정, 자막/SRT, 완성도 점검
js/media.js       미디어 불러오기, 썸네일, 파형 분석
js/export.js      내보내기 (점검 → 설정 → MediaRecorder 실시간 렌더링)
js/presets.js     필터, 자막 스타일, 움직임, 전환 프리셋
```

## 알아 둘 점

- 내보내기는 실시간으로 렌더링하므로 영상 길이만큼 시간이 걸립니다. 렌더링하는 동안에는 탭을 열어 두어야 합니다.
- 원본 파일은 브라우저 저장소(IndexedDB)에 보관되므로, 아주 큰 파일을 많이 쓰면 저장 공간이 부족할 수 있습니다.
